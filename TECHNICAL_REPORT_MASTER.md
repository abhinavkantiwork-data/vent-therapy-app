### **Project Summary**
- **Name**: VENT0.01 AI Therapy Chat Application
- **Type**: Full-Stack Web Application
- **Technology**: React + TypeScript + Python Flask + AI Integration
- **Purpose**: AI-powered mental health support with crisis detection

### **Key Features**
